# S2.5 Hardening

**As** an AP approver **I want** a paused invoice to still be waiting for me after the
system restarts, **so that** nothing is silently dropped between submission and approval.

**As** the engineer **I want** one command that scores the invoice skill on known cases,
**so that** I can change prompts or models and know whether anything got worse.

**As** a tenant admin **I want** tools to act only within my workspace whatever the caller
claims, **so that** another tenant's data is never reachable.

## Acceptance (Gherkin)

```gherkin
Scenario: approval survives a restart
  Given an invoice over the approval limit is paused for review
  When the API process restarts
  And an approver approves it
  Then the invoice is posted exactly once

Scenario: run state is private
  Then the anon and authenticated roles have no access to schema langgraph

Scenario: eval gates money safety
  When the invoice eval runs on the 15 planted invoices
  Then every case passes with the rules extractor
  And a review case that was auto-posted makes the run exit with code 1

Scenario: MCP identity from token
  Given an MCP call without a valid bearer token
  Then the tool returns ok=false with code forbidden
  And no MCP tool accepts a tenant_id argument
```

Tests: `test_checkpoint.py`, `integration/test_checkpoint_db.py`, `test_eval.py`,
`test_mcp_auth.py`.
